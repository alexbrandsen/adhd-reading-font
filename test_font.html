ADHD Font Test

How it works: This page tests the ADHD Reading Font, which should automatically bold the first 40-50% of each word. If the font is working correctly, you should see the first portion of each word below appear in bold.

Short Words (1-3 letters)

I a it is the and for

Expected: Only the first letter of each word should be bold (except 1-letter words)

Medium Words (4-6 letters)

Bold font Reading essential skill

Expected: First 2-3 letters should be bold

Long Words (7+ letters)

understanding challenging comprehension knowledge

Expected: First 40-50% of letters should be bold

Full Sentence

Reading is an essential skill for everyone. The ability to read well opens doors to knowledge and understanding. People with ADHD often find it challenging to maintain focus while reading long texts.

Troubleshooting:
  • If all characters are bold: The font features are not working correctly
  • If no characters are bold: The calt feature might be disabled
  • If it works: Congratulations! The font is working correctly

Note: This test requires that:

  1. The adhd-font.otf file is in the same directory as this HTML file
  2. Your browser supports OpenType features (all modern browsers do)
  3. The font loads successfully (check browser console for errors)
