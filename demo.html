ADHD Reading Font Demo

About: This page demonstrates the ADHD Reading Font tool, which applies bold formatting to the first 40-50% of each word to improve readability for people with ADHD. The text below shows the same content formatted with different fixation ratios (40%, 45%, and 50%).

How to Use

1. Install the tool: Run pip install -r requirements.txt

2. Process text: python adhd_font_tool.py --text "Your text" --ratio 0.45

3. Process a file: python adhd_font_tool.py --file input.txt --output output.html

4. Use with CSS: Use the Aileron font family with bold weight for the <b> tags.
